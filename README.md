# Terrain Gacha Lab

一个独立实现的程序化地形与城镇实验，用来复现「参数化设计 + seeded RNG + 水滴侵蚀 + 水文汇流 + 可达性分区」这套生成范式。

> 这不是原项目的官方版本，也不包含原项目的代码、参数表或美术资源。它只借鉴了公开页面中描述的设计思想，并用独立代码重写。原项目：<https://tools.oyasumi-gamedev.com/worldgacha/>。

## 运行

```bash
cd worldgacha-mvp
npm run serve
```

然后打开 <http://localhost:5173>。

不需要构建步骤，浏览器直接加载 ES modules。3D 视图使用仓库内 vendored 的 three.js（MIT），因此也不需要先执行 `npm install`。

## 测试

```bash
npm test
```

测试会检查：

- 同一 seed 的高度场是否确定。
- 五种地形的高度范围是否有效。
- 水滴侵蚀后是否仍然有限。
- 填洼/汇流是否产生河网。
- 闭合山谷的出口是否生效。
- 城镇道路/建筑/地块/铁路/车站是否生成，建筑是否落在有效分区。
- 铁路是否避开深水，海岛地形的铁路是否终止于海岸而不是海面。
- 同一 seed 的城镇是否确定。

## 功能

- 五种地形：河谷、海岸坡地、山间温泉谷、峡湾、火山岛カルデラ。
- 可输入/随机化 seed；同一 seed + 同一参数可复现。
- 范围 2 / 4 / 6 / 8 km，分辨率 256 / 512 / 1024。
- 可开关水滴侵蚀。
- 六种视图：彩色、高度、坡度、汇流累积、城镇、3D。
- 城镇视图自动缩放到城镇范围，方便观察道路与建筑。
- 3D 视图：地形 mesh、水面、道路带、实例化建筑、铁路、车站；拖动旋转、滚轮缩放，双击切换全图/城镇。
- 城镇分区：中心、住宅、农田、工业、集落。
- 道路网络：放射主干道、环路、支路；沿路前后两排地块，建筑带高度与类型。
- 铁路：从城镇中心附近到地图边缘（海岛地形到外海岸）的低成本路径，带桥梁判定、车站与站前建筑。
- 地块：按分区/道路等级切分面宽与进深，检查坡度、水面、铁路净空与重叠，前后排地块用于沿街与背街建筑。
- 鼠标悬停显示坐标、高度、坡度、汇流量与分区。
- 导出 PNG 与状态 JSON（含建筑数据）。
- 河网以平滑矢量折线叠加，海岸线带深度渐变。

## 算法概要

### 1. 设计图

每种地形先由 seeded RNG 生成一组有语义的参数，例如：

- 海岸线基准位置与摆动幅度
- 河流蜿蜒幅度、频率、相位
- 山脉高度、起始距离
- 山谷宽度、丘陵高度
- 域扭曲强度
- 四组噪声 seed

这些参数决定大尺度形态；噪声只负责细节。这样比“直接对 fBm 取高度”更容易得到像某种地形的结果。

### 2. 高度场

```text
世界坐标 (x, z)
  → 旋转到地形局部坐标 (u, v)
  → 低频域扭曲
  → 解析式高度函数
      = 基础坡度
      + 丘陵/山脉（fBm + ridged）
      + 河流下切（smooth min）
      + 海岸/海湾/冲沟/支沟
```

五种地形的解析式不同：

- 河谷：海岸线 + 蜿蜒主河 + 两侧山脉 + 谷底。
- 海岸坡地：海湾 + 快速上升的坡地 + 冲沟 + 小岛。
- 山间温泉谷：V 形谷底 + 陡壁 + 侧向支沟 + 山体。
- 峡湾：深切入海的长海峡 + 陡峭峡壁 + 支湾 + 外海群岛。
- 火山岛カルデラ：环形火山体 + 中央破火山口湖 + 放射状冲沟 + 外海。

### 3. 水滴侵蚀

每个水滴：

```text
沿高度梯度移动（带惯性）
  → 计算搬运能力
  → 能力不足时沉积
  → 能力有富余时侵蚀半径内的格子
  → 蒸发、减速
```

之后做：

- 热侵蚀：超过安息角的坡面物质下滑。
- 轻度模糊：形成更平滑的谷底。

### 4. 水文

```text
priority-flood 填洼
  → 每个格子选最陡下坡邻居（D8）
  → 按高程从高到低累积汇流量
  → 汇流量超过阈值的格子标记为河流
```

阈值以平方米表示，再按格子面积换算成格子数，所以同一参数在不同分辨率下仍然有意义。

### 5. 城镇

```text
从城镇中心做 Dijkstra
  → 成本 = 距离 × 坡度惩罚 × 高度惩罚 × 临水奖励
  → 按成本阈值划分 CORE / RES / IND / PADDY / HAMLET
  → 用低频噪声扰动阈值，避免完美同心圆
  → 放射主干道沿低坡度方向延伸
  → 环路 + 支路补齐街区
  → 铁路 Dijkstra + 车站选址
  → 沿道路两侧切前后两排地块
  → 在地块内放置建筑
```

- `CORE`：商业/公寓，2–8 层。
- `RES`：住宅，1–3 层。
- `IND`：仓库/工业，大面宽。
- `PADDY`：农田，少量农舍。
- `HAMLET`：沿路零星农舍。
- 建筑 footprint 是沿道路方向旋转的矩形，带高度、类型和避让检查。

铁路与地块：

- 铁路从城镇中心附近的可建陆地出发，用 8 邻域 Dijkstra 找低成本路径；深水代价极高，跨河有额外代价，坡度和高海拔也加权。
- 非海岛地形连到地图边缘；海岛地形（caldera）连到与外海相连的海岸，避免铁路跨海连到地图边界。
- 路径做平滑与距离简化；起点附近按坡度、距离、分区和临水情况选车站。
- 车站由站台、站房和线路组成；站房落在 CORE/RES/IND/HAMLET/PADDY 的合法地块上。
- 地块沿道路两侧分前后两排，按分区和道路等级决定面宽/进深；检查 9 个采样点的高度与坡度、越界、水面、铁路净空、车站净空和重叠。
- 建筑从地块内部按退界再取 footprint，地块的 `built` 标记用于统计与 JSON 导出。

### 6. 渲染

- 在 2× 输出分辨率上双线性采样高度、距离场和汇流量。
- 用高度渐变 + hillshade 着色。
- 海岸用 `dLand` 做深度渐变。
- 河网从 `dir` 追踪成折线，做 Catmull-Rom 平滑后用 Canvas 矢量描边。

### 7. 3D 视图

- 高度场按最大 512 网格重采样，生成带顶点色和法线的 three.js mesh。
- 海面是 y=0 的半透明平面；道路按折线生成三角带；建筑用 `InstancedMesh` 盒体和屋顶。
- 铁路用道砟带 + 枕木 + 双轨 + 深色描边/浅色线路叠加层；叠加层关闭深度测试，保证在全图和城镇视角都能看到走向。
- 车站有站台、站房和一根 14 m 高的琥珀色标识柱；站房采用独立类型，便于在全图里定位。
- 地形做 1.45× 垂直夸张、建筑做 1.6× 高度夸张，让 6 km 尺度下的起伏和聚落可读。
- 天空使用 Canvas 渐变纹理，建筑带接触阴影；双击在全图与城镇特写之间切换。

## 与原项目的关系

原项目 World Gacha 还包含更完整的版本：

- 9 种地形（含城下町、摩天楼、瀑布水都等）。
- 更完整的城镇系统：多线路铁路/车站、地块产权、周边集落。
- three.js 3D 场景、近景/远景 LOD、线画/网点/贝塔渲染。
- GLB / FBX / OBJ / SVG / 16bit heightmap 导出。
- Web Worker 与节点级 seed 缓存。

这个 MVP 实现了 **地形 + 侵蚀 + 水文 + 简化城镇（含铁路/车站/地块）+ 2D/3D 可视化**。它的价值是让整条生成链路可运行、可观察、可修改，而不是复刻完整产品。

## 已知限制

- 3D 是展示用实现：最大 512 网格、固定垂直夸张、无 LOD/贴图/室内；建筑只有盒体和简单屋顶。
- 城镇是简化模型：单线铁路、单车站，没有道岔、时刻表、复线或地价/产权系统。
- 地块是几何细分，不是法律意义上的产权；前后排地块的退界与重叠检查是启发式。
- 建筑是矩形 footprint，没有立面和室内细分。
- 道路可能出现短断头或跨水桥段，尚未做完整的图连通性清理。
- 铁路只在生成阶段避让深水；桥梁是视觉标记，没有结构计算。
- caldera 的中央火山口湖也算水面，铁路终点使用“与外海连通”的海洋距离场来判断，避免把线路修到火山口里。
- 分区由可达性阈值决定，可能仍带有放射状/扇形的痕迹。
- 水文是简化版：没有严格的海平面边界条件、没有湖泊/水库的复杂处理。
- 河网是单流向 D8，可能出现少量不自然的直线段。
- 侵蚀参数是独立调过的，不与原项目数值完全一致。
- 生成在主线程执行；1024 分辨率会有短暂卡顿。
- 没有实现原项目的 recipe 链接、节点锁、绘制工具。

## 可以继续做什么

1. 把生成移到 Web Worker，避免 UI 卡顿。
2. 铁路升级：多线路/环线、道岔、桥梁结构、站前广场与时刻表。
3. 地块升级：产权/地价、合并与细分、临街面宽约束。
4. 给 3D 增加 LOD、屋顶类型、阴影质量切换和 GLB 导出。
5. 继续增加地形类型（城下町、摩天楼、瀑布水都等），复用 `params + height` 接口。
6. 把 `minA`、`talus`、侵蚀参数暴露到 UI，做参数实验。
7. 用 Playwright 做截图回归，监控视觉变化。
8. 调整 caldera 的城镇密度和火山口雪线，让城市更贴合火口湖地形。
